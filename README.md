# 골조 검측 현황판

건축팀 시공관리용 웹 현황판입니다. 동 탭으로 나눠 층별·부위별 검측완료 일자를 관리하고,
끊어치기(분할 타설) 차수를 각각 기록합니다. 슬랙에서 말로 입력하는 것도 됩니다.

- **자동 저장** — 저장 버튼 없음. 입력하면 바로 저장되고 다른 사람 화면에 몇 초 안에 반영됩니다.
- **여러 명 동시 입력** — 칸 단위로 저장돼서 서로 덮어쓰지 않습니다.
- **폰에서도 사용** — 홈 화면에 추가하면 앱처럼 열립니다.
- **재배포해도 데이터 유지** — 기능을 추가해도 입력한 일자는 그대로입니다. (코드와 데이터가 분리돼 있습니다)

---

## 1. 배포하기 (처음 한 번, 약 15분)

### 1-1. Vercel 가입 및 프로젝트 만들기

1. [vercel.com](https://vercel.com) 에 GitHub 계정으로 가입
2. **Add New… → Project** → 이 저장소 선택 → **Import**
3. 설정은 아무것도 건드리지 말고 **Deploy** 클릭
4. 첫 배포는 실패해도 정상입니다. 데이터베이스를 아직 안 붙였기 때문입니다.

### 1-2. 데이터베이스 붙이기

1. 방금 만든 프로젝트 → 위쪽 **Storage** 탭
2. **Create Database → Postgres** 선택 → 이름 아무거나 → **Create**
3. 만들어진 데이터베이스를 이 프로젝트에 **Connect**

이러면 `DATABASE_URL` 이 자동으로 들어갑니다. 표(테이블)는 처음 접속할 때 알아서 만들어집니다.

### 1-3. 비밀번호 정하기

**Settings → Environment Variables** 에서 아래를 추가합니다.

| 이름 | 값 | 설명 |
|---|---|---|
| `APP_PASSWORD` | 현장에서 정한 비밀번호 | 이게 없으면 링크 아는 사람 누구나 들어옵니다 |
| `APP_SECRET` | 아무 긴 문자열 | 로그인 유지용. 바꾸면 다들 다시 로그인 |
| `MCP_TOKEN` | 길고 랜덤한 문자열 | 슬랙 연동할 때 씀 (2단계에서 사용) |

> `MCP_TOKEN` 은 아무거나 길게 만드시면 됩니다. 예: `gjcheck-8f2k9d0aq7xzm3`

### 1-4. 다시 배포

**Deployments** 탭 → 맨 위 배포의 **⋯ → Redeploy**

끝나면 `https://프로젝트이름.vercel.app` 으로 들어가서 비밀번호를 넣으면 현황판이 나옵니다.
처음 들어가면 **4개 동 / 옥탑2~B2 24개 층 / 층마다 4칸**이 기본으로 만들어져 있습니다.

### 1-5. 팀원들에게 알려주기

- **PC** — 주소를 즐겨찾기에 추가하거나, 바탕화면에 바로가기를 만듭니다.
- **폰** — 주소 접속 후 브라우저 메뉴에서 **홈 화면에 추가**. 앱 아이콘처럼 열립니다.

## 2. 슬랙 연동하기 (선택, 약 10분)

슬랙에서 이렇게 쓸 수 있게 됩니다.

```
나:     @Claude A동 3층 슬라브 7/26 검측완료, 메모 300M3
Claude: 저장했습니다.
        위치: A동 3F 슬라브
        1차: 2026-07-26
        현재 상태: 검측완료 2026-07-26
        메모: 300M3
```

### 2-1. 슬랙에 Claude 앱 설치

Claude 구독(Pro/Max/Team)이 있으면 API 키 없이 연결됩니다.
Claude 설정에서 슬랙 연동을 켜고, 워크스페이스에 Claude 앱을 설치합니다.

### 2-2. 커넥터 연결

Claude 설정 → **커넥터(Connectors) → 커스텀 커넥터 추가**에 아래 주소를 넣습니다.

```
https://프로젝트이름.vercel.app/api/mcp?token=아까_정한_MCP_TOKEN
```

연결되면 Claude가 아래 기능을 쓸 수 있게 됩니다.

| 도구 | 하는 일 |
|---|---|
| `record_inspection` | 검측완료 일자 기록 (차수·비고·메모 포함) |
| `get_status` | 특정 동/층/부위 현황 조회 |
| `list_structure` | 어떤 동·층·부위가 있는지 확인 |
| `set_memo` | 메모만 수정 |
| `recent_activity` | 최근 기록 확인 |

### 2-3. 쓸 때 요령

**위치를 같이 말해주세요.** 동·층·부위가 있어야 저장됩니다.

```
O   A동 3층 슬라브 7/26 검측완료
O   B동 지하2층 TG보 3차까지 끊어치는데 1차 7/14 완료
X   7월 26일 검측완료          ← 어디인지 몰라서 Claude가 되묻습니다
```

**채널을 동별로 나누면 더 편합니다.** `#a동-검측` 채널에서는 "3층 슬라브 7/26 완료"만 쳐도
Claude가 A동인 걸 압니다. (채널 주제나 첫 안내 메시지에 "여기는 A동" 이라고 적어두세요)

**날짜는 편하게 쓰셔도 됩니다.** `7/26`, `7월 26일`, `2026-07-26`, `오늘` 다 알아듣습니다.

**끊어치기는 차수를 말해주세요.**
`3차까지 끊어치는데 1차 완료` → 1차만 채우고 2·3차는 미완으로 남겨둡니다.

**저장한 뒤 Claude가 요약해 줍니다.** 틀렸으면 바로 `아니 4층이야` 하고 고치면 됩니다.

## 3. 화면 사용법

### 평소 (보기 모드)

- **탭**으로 동을 고릅니다. 탭에 동별 진행률(%)이 보입니다.
- **칸을 누르면** 입력창이 열립니다.
  - 맨 위 **이 칸 이름** — 칸마다 따로 고칠 수 있습니다 (`보` → `TG보`)
  - **차수 추가 (끊어치기)** — 1차·2차·3차… 각각 날짜와 구간·비고를 적습니다
  - **메모** — 자유 기입 (예: `300M3`)
- 색으로 상태가 보입니다.

| 색 | 뜻 |
|---|---|
| 🟩 초록 | 모든 차수 완료 |
| 🟨 노랑 | 일부 차수만 완료 (예: `2/3차`) |
| ⬜ 회색 | 미완 |

### 편집 모드 (`✎ 편집`)

- 칸을 **끌어서** 다른 자리·다른 층으로 옮깁니다. 줄은 자동 정렬됩니다.
  - 마우스 없이: 칸 선택 후 **Ctrl + 방향키**
- 동·층·칸 **추가/삭제/이름변경**
- **모든 동에 같이 적용** 체크 — 층을 고칠 때 4개 동에 한 번에 반영
- **📂 기존 HTML 가져오기** — 공유폴더에서 쓰던 `골조검측현황.html` 을 올리면
  입력해둔 일자·차수·메모가 통째로 넘어옵니다

## 4. 자주 나오는 질문

**Q. 기능을 추가하면 그동안 입력한 데이터가 날아가나요?**
아닙니다. 코드(Vercel)와 데이터(DB)가 따로 있어서 재배포해도 데이터는 그대로입니다.
데이터 구조 자체를 바꾸는 기능일 때만 옮기는 작업이 필요한데, 그건 코드에 같이 넣어 처리합니다.

**Q. 두 사람이 같은 칸을 동시에 고치면?**
나중에 누른 쪽이 남습니다. 다만 **칸 단위로 저장**되기 때문에 서로 다른 칸을 만지면 전혀 안 겹칩니다.
공유폴더 HTML처럼 파일 전체가 덮어써지는 일은 없습니다.

**Q. 인터넷이 끊기면?**
못 봅니다. 현장 인터넷이 자주 끊긴다면 공유폴더 HTML 버전을 백업으로 같이 두세요.

**Q. 비밀번호를 바꾸려면?**
Vercel → Settings → Environment Variables 에서 `APP_PASSWORD` 를 바꾸고 Redeploy 하세요.

**Q. 데이터 백업은?**
Vercel의 Storage 화면에서 데이터베이스 백업을 받을 수 있습니다. 큰 변경 전에 한 번 받아두시면 안전합니다.

## 5. 개발자용

```bash
npm install
cp .env.example .env      # DATABASE_URL 등을 채웁니다
npm run dev               # http://localhost:3000
```

| 경로 | 설명 |
|---|---|
| `app/page.js`, `components/Board.jsx` | 현황판 화면 |
| `app/api/board` | 전체 조회 / 구조 저장 |
| `app/api/cell` | 칸 단위 저장 |
| `app/api/mcp` | 슬랙(Claude) 연동용 MCP 서버 |
| `app/api/import` | 기존 HTML 가져오기 |
| `lib/db.js` | Postgres 스키마·조회·저장 |
| `lib/locate.js` | "A동 3층 슬라브" 같은 말을 실제 칸으로 찾기 |
| `lib/seed.js` | 처음 만들어지는 기본 현장 구성 |

데이터 구조는 **구조(layout)** 와 **칸 데이터(cells)** 로 나뉩니다.
구조는 가끔 바뀌고 통째로 저장하며, 칸 데이터는 자주 바뀌므로 칸 하나씩 저장해 충돌을 피합니다.
