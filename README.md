# 현장문서 3종 세트

시공사 건축팀 실무자를 위한 오프라인 문서 자동화 도구 모음.
서버 없음, 설치 없음 — HTML 파일을 브라우저로 열면 바로 동작합니다.

| 도구 | 파일 | 설명 |
|---|---|---|
| 📷 사진대지 자동 생성기 | [`tools/photo-report.html`](tools/photo-report.html) | 사진 드래그앤드롭 → A4 사진대지. EXIF 촬영일 자동 인식, 2/4/6장 레이아웃, 프로젝트 저장/불러오기 |
| 📋 공사일보 작성기 | [`tools/daily-report.html`](tools/daily-report.html) | 출역인원·장비·자재·작업사항 입력 → 결재란 포함 A4 공사일보. 전일 복사, 자동 저장 |
| 🧮 현장 물량 계산기 | [`tools/calculator.html`](tools/calculator.html) | 콘크리트 타설량(레미콘 대수), 철근 중량, 거푸집, 벽돌/블록, 타일 |

`index.html`은 소개/판매 랜딩페이지입니다. GitHub Pages를 켜면 그대로 데모 사이트가 됩니다.

## 사용법

1. 파일을 다운로드해 크롬/엣지로 엽니다 (더블클릭).
2. 내용 입력 후 **인쇄 / PDF 저장** 버튼 → 브라우저 인쇄 대화상자에서 "PDF로 저장".
3. 인쇄 설정에서 **여백: 없음, 배경 그래픽: 켜기**를 권장합니다.

모든 데이터는 사용자 PC의 브라우저 안에서만 처리되며 외부로 전송되지 않습니다.
