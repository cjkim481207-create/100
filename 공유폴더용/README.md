# 공유폴더용 오프라인 버전

인터넷이 끊겼을 때를 대비한 백업본입니다. 평소에는 웹 현황판을 쓰세요.

`골조검측현황.html` 파일 하나에 프로그램과 데이터가 같이 들어 있습니다.
서버도 인터넷도 필요 없고, 공유폴더에 두고 더블클릭하면 열립니다.

## 쓰는 법

1. 공유폴더에 `골조검측현황.html` 을 둡니다.
2. **Chrome 또는 Edge**로 엽니다. (인터넷 익스플로러는 안 됩니다)
3. 칸을 눌러 검측 일자·차수·메모를 입력합니다.
4. **`💾 저장`** 을 누르면 저장창이 뜹니다. 여기서 **공유폴더의 원래 파일을 선택해 덮어쓰세요.**

## 주의

- **저장하지 않으면 다른 사람에게 반영되지 않습니다.** 웹 버전과 달리 자동 저장이 아닙니다.
- 두 사람이 동시에 고치고 각자 저장하면 나중에 저장한 쪽이 앞사람 것을 덮어씁니다.
  → 수정 담당을 한 명으로 정하는 게 안전합니다.
- 메모장이나 워드로 편집하지 마세요. 한글이 깨집니다.
- 주 1회 정도 파일 사본을 `백업` 폴더에 남겨두세요. (저장 파일명에 날짜·시각이 자동으로 붙습니다)

## 웹 현황판으로 옮기기

여기에 쌓인 데이터를 웹 현황판으로 그대로 가져갈 수 있습니다.

웹 현황판 → **✎ 편집** → **📂 기존 HTML 가져오기** → 이 파일 선택
